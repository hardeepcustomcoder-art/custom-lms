# Custom LMS WordPress Plugin

A custom WordPress Learning Management System (LMS) plugin featuring course management, lessons, topics, quizzes with randomized questions and answers, WooCommerce payment integration, progress tracking, admin design customization with live preview, and admin-authorized quiz retakes.

## Features

- **Courses, Lessons & Topics:** Hierarchical curriculum flow with topic completion tracking.
- **Interactive Quizzes:**
  - Manually managed questions and multi-choice options in the backend.
  - Question & answer option randomization per attempt.
  - Automatic evaluation, scoring, and email notifications to students.
  - Single submission enforcement with admin-authorized retakes.
- **Admin Design Customizer:**
  - Live preview of quiz and course buttons, backgrounds, and progress bars.
  - Settings tabs for design colors with reset to defaults.
- **WooCommerce Integration:** Sell access to paid courses with automated enrollment on completed orders.
- **Free Preview:** First topic accessible for preview with sign-in/register modal.

## Requirements

- WordPress 6.0 or higher
- PHP 7.4 or higher
- WooCommerce (optional, for paid course sales)
